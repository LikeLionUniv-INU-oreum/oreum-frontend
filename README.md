## 📂 Project Structure

```text
ORUM-FRONTEND/
├── public/                 # 정적 리소스
└── src/
    ├── api/                # API 통신 관련 (Axios 인스턴스, 요청 함수 등)
    ├── assets/             # 컴포넌트 내부 이미지/아이콘
    ├── components/         # 공통 UI 컴포넌트
    ├── pages/              # 개별 페이지/스타일 파일
    ├── styles/             # 전역 스타일 (레이아웃, 폰트 등)
    ├── App.jsx             # 최상위 루트 컴포넌트
    └── main.jsx            # 엔트리 포인트
```
